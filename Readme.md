# 🔒 Web Security Application 

A web application for testing and learning **web security vulnerabilities**. Built entirely with **PHP**, **Bootstrap**, **CSS**, **JS**, and image assets, this app includes intentional security scenarios for educational purposes such as **SQL Injection**, **XSS**, and more.

## ✨ Features

### 🎯 Core Features
- **Web security testing**: Practice vulnerabilities like SQL Injection, XSS, CSRF
- **User authentication**: Login system for testing security scenarios
- **Interactive UI**: Bootstrap-based interface with forms, tables, and alerts
- **Image & media support**: Handles static assets for demonstration

### 🎨 User Interface
- **Responsive design**: Works on desktop and mobile
- **Bootstrap 5**: Modern, clean and consistent UI
- **Realistic scenarios**: Forms and inputs to test vulnerabilities
- **Dynamic content**: JS and PHP interactions

### 🔧 Technical Features
- **PHP backend**: 100% server-side logic in PHP
- **Bootstrap + JS frontend**: Responsive UI components
- **Static assets**: Images, CSS, JS included for full functionality
- **Standalone**: No database required for basic scenarios (optional MySQL for advanced cases)
